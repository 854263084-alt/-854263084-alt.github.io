# 链潮 · 币圈趋势雷达

手机优先的中文 PWA，用于追踪币圈市场阶段、热点叙事、热门搜索、价格异动、项目事件和个人自选。

## 在线地址

https://854263084-alt.github.io/-854263084-alt.github.io/

## 使用

直接打开 `index.html` 即可查看。部署到 HTTPS 网站后，可在手机浏览器中“添加到主屏幕”。

## 数据更新范围

- 自动更新：全市场市值、BTC 市占率、成交额、恐惧贪婪指数、CoinGecko 热搜、观察池行情和板块数据。
- 版本更新：叙事研究、项目风险和内置事件日历。
- 本机保存：自选币、自定义事件和价格提醒。

公开接口存在访问频率限制；接口暂时不可用时，应用会显示最近缓存或带有明确标记的离线快照。
