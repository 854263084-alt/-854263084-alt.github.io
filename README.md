# 链潮 · 币圈趋势雷达

手机优先的中文 PWA，用于追踪币圈市场阶段、热点叙事、热门搜索、价格异动、重要事件和个人自选。

## 在线地址

https://854263084-alt.github.io/-854263084-alt.github.io/

## 使用

直接打开 `index.html` 即可查看。部署到 HTTPS 网站后，可在手机浏览器中“添加到主屏幕”。

## 自动更新范围

- CoinGecko：全市场市值、BTC 市占率、成交额、恐惧贪婪、热门搜索、主线池和高成交量币种。
- DexScreener：公开 DEX 注意力/推广信号；它只代表注意力，页面会明确标为高风险，不等同于上所或投资建议。
- 公开宏观日历：筛选美国 CPI、非农、FOMC 相关事件及其他重要美元数据，统一换算为北京时间。
- 公开新闻/公告流：自动分类交易所上币下币、解锁、空投、项目上线/升级、风险和监管事件；标题保留原文，中文只给核查提示。
- 本机快照：用上一次市场观察计算成交额变化和持续性。首次出现的币种会显示“待验证”，不会假装已验证趋势。
- 本机保存：自选币、自定义事件和价格提醒。

## 数据可用性

这是纯 GitHub Pages 前端，没有 API Key，也不会把密钥放进仓库。公开接口可能限流、跨域受限或临时不可用：

- 有最近成功数据时，界面会明确标记为“缓存”并显示其更新时间。
- 没有缓存时，界面显示“不可用”，不会填充模拟行情、固定新闻或固定日历。
- 结论是规则化观察，不是投资建议；请打开公告或新闻原文核实。
